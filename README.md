# 品牌 Logo 素材庫

巨思文化媒體創意中心內部使用。統一存放各家公司/品牌 logo，避免重複上網搜尋。

## 結構

```
logo-library/
├── index.json     ← 資料索引（中英文名稱對照 + 檔案路徑），AI 查詢/新增都靠這份
├── index.html     ← 網頁搜尋介面，給人瀏覽下載用
└── assets/        ← 實際 logo 檔案
```

## 命名規則

`中文名_英文名_logo_[版本標籤].副檔名`（只有單一版本時可省略標籤）

例如：
- `台積電_TSMC_logo.svg`（只有一種版本）
- `輝達_NVIDIA_logo_直式.svg`、`輝達_NVIDIA_logo_橫式.svg`（有多版本時）

## 多版本（variants）說明

`index.json` 中每家公司用 `variants` 陣列存放多個版本（直式/橫式/單色版等）。
**只有在確認官方真的有提供該版本時才新增**（例如查到官方品牌頁面明確列出 vertical/horizontal），不要自己用同一張圖假造不同排版。

## 抓取格式優先順序

找到多種格式時，依此順序選擇：

**SVG > EPS / AI / PDF > PNG > JPG**

- SVG 向量、可縮放，優先
- EPS/AI/PDF 為印刷用向量格式，次選
- PNG 有透明背景，堪用
- JPG 無透明背景、有壓縮失真，最後選項

## 查找／新增流程

1. **先查 `index.json`**：用中文名、英文名或別名比對，找到就直接用 `assets/` 裡的檔案
2. **查不到才搜尋**：優先找官方來源（官網 press kit、品牌識別頁、Wikimedia Commons），避免抓到未授權或低解析度圖檔
3. **下載後歸檔**：
   - 檔案依命名規則放進 `assets/`
   - 在 `index.json` 的 `logos` 陣列裡新增一筆紀錄（中文名稱、英文名稱、別名、檔案路徑、來源網址、版權備註、新增日期）
4. **不要覆蓋既有檔案**：同一家公司若有新版 logo，另存新檔名（可加版本或年份），不要直接蓋掉舊檔

## 人工上傳 logo 流程（使用者在對話框直接附加圖檔）

1. 使用者附加圖片，直接由圖片內容辨識這是哪家公司（不用回頭問使用者）
2. 用 web_search 確認該公司正式中文名稱、英文名稱、常見別名（不要自己翻譯或猜測）
3. 判斷格式：
   - 上傳檔案已是 SVG/EPS/AI/PDF → 直接採用，不用再找
   - 上傳檔案是 PNG/JPG → 依「抓取格式優先順序」再搜尋一次官方來源，找到更高優先格式就換用官方版；找不到才用使用者提供的檔案
4. 依命名規則存檔（中文名_英文名_logo_[版本標籤].副檔名）
5. 查 `index.json` 是否已有該公司：
   - 已有 → 直接判斷這是新 variant 還是重複既有版本，用適當標籤新增（如「橫式」「純文字版」），不用先問
   - 沒有 → 新增一筆完整資料（中文名稱/英文名稱/別名/variants/新增日期）
6. `git add . && git commit && git push`，確認 GitHub Pages 部署完成
7. **不覆蓋既有檔案**：同公司有新版本一律另存新檔名
